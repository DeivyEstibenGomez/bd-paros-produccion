# Carpeta privada

Aquí el ETL deja los archivos con nombres reales de personas:

- `identidades.sql`: carga `privado.persona_identidad` (seudónimo → nombre).
- `mapa_personas.csv`: tabla de correspondencia para el equipo.
- `alias_personas.csv`: variantes de nombre que se deben unir (lo mantiene el equipo).

Todo lo que hay en esta carpeta, salvo este archivo, está en `.gitignore`. No lo suban a GitHub.
